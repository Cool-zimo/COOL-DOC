快速开始

登录、上传、下载基础操作

快速开始

1. 登录

  1. 打开 GitHub Drive
  2. 输入 GitHub Personal Access Token（需要 repo 权限）
  3. 点击「验证并进入」

Token 仅保存在浏览器本地，不会上传到任何服务器。

2. 上传文件

  • 点击工具栏「⬆️ 上传文件」，选择一个或多个文件
  • 或直接拖拽文件到页面区域
  • 大文件自动分片存储到多个 GitHub 仓库

3. 上传文件夹

  • 点击「📂 上传文件夹」，选择本地文件夹
  • 自动保持目录结构，递归上传所有文件

4. 管理文件

  • 双击文件夹进入，双击文件预览
  • 右键文件：重命名、移动、复制、删除、收藏、分享、下载
  • Ctrl/Cmd + 点击多选文件，批量操作
  • 拖拽文件到文件夹或面包屑路径，移动文件

5. 分享文件

  • 右键文件 → 分享
  • 填写分享名称和描述
  • 自动创建公开仓库 + GitHub Pages
  • 分享链接可直接访问，支持下载全部文件

6. 插件

  • 侧边栏 → 🧩 插件广场
  • 浏览插件，点击「安装」
  • 点击「运行」全屏打开插件，按 ESC 或点右上角「✕ 关闭」退出

7. 仓鼠（配套应用）

仓鼠是配套的 GitHub 仓库管理面板，可卡片化管理多个仓库。

  • 地址：https://cool-zimo.github.io/cangshu/
  • 登录一次，两边都进：两个应用同源于 cool-zimo.github.io， 令牌在浏览器本地共享，一边登录另一边自动识别
  • 在 Drive 侧边栏底部可一键跳到仓鼠，反之亦然
