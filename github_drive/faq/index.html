FAQ

常见问题

一般

Token 安全吗？

Token 只保存在你的浏览器 localStorage，不会上传到任何服务器。 建议创建最小权限的 Token，只勾选需要的仓库与权限。

换浏览器/设备后数据还在吗？

  • 文件：存在 GitHub 仓库里，换设备登录即可看到
  • 分享列表：直接从你的 GitHub 账号扫描 gd-share-* 仓库， 不依赖本地记录，换设备照样看得到
  • 插件：存在本地 localStorage，换设备需要重新安装
  • 仓鼠管理列表：存在私有仓库 cangshu-config，跨设备一致

大文件有大小限制吗？

单个文件建议不超过 100MB。超过会自动分片存储到多个仓库。 GitHub 单仓库建议控制在 1GB 以内。

分享

分享的 mp3/视频下载失败？

已修复（v0.0.32）。此前合并分片后没带 owner/repo， 请求打到 /repos/undefined/undefined/... 导致 404。 已生成的旧分享页不会自动更新，需要重新分享一次。

分享页面一直显示 "Loading files..."？

已修复（v0.0.33）。生成页的内联脚本有语法错误， 整段 script 不执行。重新分享一次即可。

分享会占我的仓库额度吗？

会。分享会创建一个公开仓库（如 gd-share-xxx）。 在「我的分享」里删掉分享会同时删除该仓库。

插件

插件是怎么运行的？

插件是独立的 HTML 文件，在 iframe 沙箱中全屏运行， 通过 postMessage 与主应用通信，无法直接访问主应用 DOM。

为什么我的插件收不到宿主响应？

  1. 确认 action 名称正确 —— 用 api.listActions 核对
  2. 确认是在 iframe 中运行（直接打开 HTML 文件拿不到响应）
  3. 检查 call() 是否带了超时保护
  4. 多开插件时若用的是老版本封装，可能被覆盖（v0.0.37 已修复）

插件能全屏吗？

自 v0.0.37 起所有插件都全屏，不需要额外配置。 旧的 fullscreen: true 字段保留也不会出错。

第三方插件安全吗？

第三方插件（GD-Plugin-* 仓库）未经审核，安装时会显示安全警告。 请自行判断代码是否可信。

仓鼠联动

为什么登录一个，另一个也进去了？

两个应用同源于 cool-zimo.github.io，localStorage 共享令牌。 这是刻意设计 —— 登录一次两边都进。

在仓鼠删掉仓库，GitHub 上的仓库会没了吗？

不会。 移除只是从管理列表删掉记录，GitHub 仓库本身不受影响。

仓鼠的配置存在哪？

私有仓库 cangshu-config/cangshu.json。 所以换设备、换浏览器都能读到。

故障排查

页面白屏或功能异常

  1. 强制刷新（Ctrl/Cmd + Shift + R）—— GitHub Pages 有 CDN 缓存
  2. 检查浏览器控制台有无红色报错
  3. 确认 Token 权限是否足够（需要 repo）

上传/下载慢

GitHub API 有速率限制（每小时 5000 次）。 大文件分片会消耗较多请求，建议避开高峰时段。
