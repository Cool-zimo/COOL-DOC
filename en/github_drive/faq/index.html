FAQ

File size limits, repo limits, CORS, multiple accounts.

How large can a single file be?

GitHub caps a single file at 100MB. Larger files are chunked automatically across several repositories and reassembled on read. The process is transparent.

How much can I store?

It depends on your GitHub account quota. Free accounts have no hard total limit, but keeping a single repository under 1GB is advisable — Git operations slow down noticeably beyond that.

Why would I need the local backend?

Talking to the GitHub API directly from the browser hits CORS restrictions, and some networks (corporate ones especially) will fail. In that case run the local server, which provides a CORS proxy, Bilibili video resolution, and command execution.

Multiple accounts?

Yes. The sidebar can switch between several GitHub accounts, each with its own independently stored token.

Where is plugin data stored?

Plugin HTML lives in browser localStorage and does not sync across devices — where a plugin keeps its own data is up to the plugin.
