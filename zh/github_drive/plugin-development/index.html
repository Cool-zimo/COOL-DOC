插件开发

建一个 GD-Plugin-xxx 仓库就能被插件广场搜到。

插件就是一个仓库

仓库名以 GD-Plugin- 开头，插件广场会自动搜到。

GD-Plugin-MyTool/
  plugin.json
  index.html

plugin.json

{
  "name": "MyTool",
  "version": "1.0.0",
  "description": "一句话说明这个插件做什么",
  "author": "your-name",
  "entry": "index.html",
  "icon": "🧩"
}

页面里能用什么

插件在 iframe 里全屏运行，通过 postMessage 跟宿主通信。

可参考 GD-Plugin-CoolClock， 照它的结构改就能做自己的。

桌面版才有能力

网页版插件跑在浏览器沙箱里，碰不到本地文件系统。

需要读写本地文件、执行系统命令的话，要用 桌面版 或 gdpy。两者都带权限模型兜底。

发布

推到 GitHub，仓库名以 GD-Plugin- 开头即可。 插件广场搜索有延迟，刚推的可能要等几分钟。
